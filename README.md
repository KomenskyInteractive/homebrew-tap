# Komensky Interactive Homebrew tap

```bash
brew install komenskyinteractive/tap/backlog-komensky
```

| Formula | What it is |
|---|---|
| `backlog-komensky` | [Backlog.md](https://github.com/MrLesk/Backlog.md) with our changes. Replaces Homebrew's `backlog-md`: run `brew uninstall backlog-md` first. |

To publish a new version, update the formula's `url`, `version` and `sha256` from the
release's `.sha256` file.
